# Demo media

[Hardware startup recording](bmo-hardware-demo.mov) is the original user-recorded
video of the physical prototype (approximately 16 MB). The main README links
directly to it. Playback support depends on the viewer's browser and codecs.

## Photo gallery

Original user-supplied photos, copied from Downloads with descriptive filenames.
The main README displays the expressions first, followed by the hardware.

| Filename | Caption |
|---|---|
| `hardware-pi.jpg` | Powered Raspberry Pi with fan and GPIO jumper wires |
| `probe-adapter.jpg` | Connected probe adapter with GND/DAT/VCC labels |
| `oled-normal.jpg` | Smiling face at 35.3 F |
| `oled-warm.jpg` | Worried face at 41.7 F |
| `oled-cold.jpg` | Zigzag mouth and C-C-Cold at 27.5 F |

Use the correct extension for each actual file; renaming a WebP to JPG does
not convert it. Choose sharp, tightly framed images with readable display text.
Review photos and video for passwords, private screens, and unrelated personal
details before publishing. Keep original captures separately.
